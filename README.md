# 🪽 Nanhe Pankh — Website

**Giving wings to every child's dreams.**

Nanhe Pankh is a grassroots initiative focused on supporting underprivileged children by improving access to basic education, learning resources, digital exposure, and community awareness.

## Website Pages

- `index.html` — Home
- `vision.html` — Vision & Overview
- `mission.html` — Mission & Impact
- `about.html` — Founder & Co-Founder
- `contact.html` — Contact Us / Google Form

## Included Assets

- Founder portrait
- Co-Founder portrait
- Official Nanhe Pankh logo variations
- Nanhe Pankh wing mark
- Official homepage banner

All supplied image assets have been included in the `images/` folder.

## Design

The website uses the visual identity from the supplied Nanhe Pankh artwork:

- **Deep Navy:** `#202D49`
- **Navy Deep:** `#18233A`
- **Warm Gold:** `#C9A75F`
- **Light Gold:** `#E4CF9C`
- **Warm Cream:** `#F8F6F0`
- **Paper White:** `#FFFDF8`

The layout is responsive and includes a mobile navigation menu, subtle scroll-reveal animations, rounded cards, and consistent typography.

## How to Run

No server or build tools are required.

1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Use the navigation to move between pages.

For deployment, upload the entire folder to a static hosting service such as GitHub Pages, Netlify, or Vercel.
